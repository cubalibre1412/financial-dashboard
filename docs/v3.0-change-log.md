## 반영한 사용자 승인 기준

1. 대표 TSR = 세전·귀속연도 DPS·비재투자. 기간 시작 주가 대비 종료 주가 변동과 기간 DPS 합계 가산. 연간 TSR 연쇄곱을 비재투자 누적으로 사용하지 않음.
2. 기존 재투자 TSR은 보조 값. 벤치마크 센터는 TR과 비교하므로 재투자 기준 유지. 요약에는 구분 표시.
3. 대표 피어는 풀무원 제외 5사 중앙값. 삼양도 제외한 4사 중앙값은 보조. A·D·비교 매트릭스·배수 비교도 풀무원 제외 통계 적용. 표의 개별 회사 행은 6개사 유지.
4. 순차입금과 Net Debt 분리. Net Debt는 순차입금+리스+신종자본증권+비지배지분. EV=시가총액+Net Debt.
5. 반기 현재 평가 이익은 TTM. 연말 전망은 올해 상반기 실제+하반기 예상.
6. 하반기 기본 예상은 전년 하반기 수준 유지. EBIT와 상각비 3종을 별도 조정. 회사 승인 전망이 아닌 가정임을 표시.

## 신규 시뮬레이션 계산과 보호 장치

- 기준 전망·개선·하방은 동일한 가정에서 시작. 사용자가 시나리오별 입력을 변경. 이름만으로 다른 가정을 자동 생성하지 않음.
- 기본 Multiple=FY2025 정확한 EV/EBITDA, 기본 DPS=102원, 연말 자본구조=반기 잔액. 모두 미승인 가정.
- 승인 목표가 비어 있으면 달성 여부 판정하지 않음.
- 배당대상 주식수는 가치평가 주식수와 별도 입력. 한도·배당대상주식수 미입력 시 배당 가능 판정 금지.
- 배당가능이익 감소 가정은 별도 항목. Net Debt로 자동 연결하지 않음.
- 귀속연도와 지급연도 구분. 다음 연도 지급 배당을 당해 말 Net Debt에서 자동 차감하지 않음.
- 현금으로 차입금 상환 시 순차입금 불변 검증. EBITDA 개선을 자동 현금 개선으로 중복 반영하지 않음.
- 비양수 EBITDA·Multiple·주식수·시가총액, 음수 재무 잔액, 미입력 필수값은 계산 불가 처리.
- 주식수 변화는 네 요인 외 별도 효과로 분해. 기여도 합계 잔차 허용오차 1e-10(수익률 단위).
- 시뮬레이션 저장 키 `pulmuone_tsr_scenarios_v3`. 실제 데이터 저장 키와 분리. 기준 데이터가 바뀐 저장본은 자동 적용하지 않음.

## 남은 범위와 운영 인수 조건

- 승인 Plan의 상세 재무 구성 입력, 시뮬레이션 전용 Excel 가져오기/내보내기, 자동 최적 조합 탐색은 이번 구현에 포함하지 않음. 현재는 승인 TSR 목표와 수동 시나리오 비교·단독 조정 역산.
- 가치구조는 동일 축척 누적 막대로 구현. PPT의 EBITDA 가로×Multiple 세로 면적형 시각화는 미구현.

- 5개 타사 TTM 재무 전수 재감사, 배당한도 법적 검증, 모든 업로드·편집 회귀검사는 이번 범위 밖.
- 원본 Excel 수정은 별도 진행된 작업과 충돌 방지를 위해 이번 코드 작업에서 수행하지 않음. 재추출 시 위 승인 교정 수치를 확인.
- 운영 배포 전 동일 Vercel 프로젝트 연결 확인, 최신 코드 및 본 기록 인수, 밝은 화면 승인 필요. SSL 검증 해제 금지.
