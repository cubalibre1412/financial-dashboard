## 3. 산식 및 정책 유지

- 대표 TSR: 세전·귀속 DPS 기준 비재투자. 재투자 TSR은 보조.
- 피어: 풀무원 제외 5사 중앙값 우선, 삼양식품 제외 4사 중앙값 보조.
- 사채: 장부금액 기준.
- 순차입금: 차입금 − 현금및현금성자산 − 단기금융자산 − 단기투자자산.
- Net Debt: 순차입금 + 리스부채 + 신종자본증권 + 비지배지분.
- EV: 시가총액 + Net Debt.
- 2026H1 배수: TTM EBITDA·TTM 지배주주순이익 기준. 반기 실제 실적과 별도 표기.

## 4. 배포 전·후 필수 확인

1. `npm run data:check`, `npm run build`, `npm run lint` 실행.
2. 시크릿 창에서 운영 URL 접속 후 데이터 패키지 버전·갱신 시각 대사.
3. 검색된 2025 행의 수정·삭제 대상, 원본 복원, 반기 필터, 신규 입력 대상 기업 확인.
4. KOSPI·생활소비재·채권종합·국채·아파트 비교지수와 5년 선택 확인.
5. 운영 배포 URL·데이터 버전·검수 결과·미확인 사항을 배포 기록에 남김.
6. `npm run audit:context`로 풀무원 전용 기능의 타사 노출, 선택 기업 자기 포함 피어 통계, 음식료업종 TR 표기 재삽입을 자동 차단.

## 5. 범위 외·후속 과제

- ROE 원천 정의 확정 전 재계산 기준 변경 금지.
- 2026H1 구성항목을 화면에서 수정할 때 TTM은 자동 재산출 근거가 없으면 별도 검증·입력 필요.
- 단기·장기차입금 원천 상세를 자본구조 화면에 추가하는 작업은 표시 추적성 개선 과제이며, 현 총차입금·순차입금·Net Debt 산식 수정과는 별개.
