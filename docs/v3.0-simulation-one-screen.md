## 계산 기준
- 비재투자 누적 TSR = (예상 기말주가 − 해당 기간 기초주가 + 과거 귀속 DPS 합 + 2026 예상 DPS) / 기초주가.
- 목표 주가 증가분 = max(0, 목표 TSR − 현재 예상 TSR) × 해당 기간 기초주가.
- 필요 EBITDA = 현재 EBITDA + 목표 주가 증가분 × 주식수 / 배수.
- 필요 Net Debt = 현재 Net Debt − 목표 주가 증가분 × 주식수.
- 필요 배수 = 현재 배수 + 목표 주가 증가분 × 주식수 / EBITDA.
- 필요 DPS = 현재 DPS + 목표 주가 증가분.
- 네 행은 각각 단독 대안. 합산 적용 금지. 미입력 목표 또는 필수 원천값 누락은 역산하지 않음.
- 빈 입력은 0이나 기준값으로 치환하지 않음. 기계적 산술 분해를 인과관계로 설명하지 않음.
