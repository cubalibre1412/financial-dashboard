# v2.8 로컬 수정 및 검증 기록

작성일: 2026-09-08

## 상태와 범위

- 사용자 승인에 따라 기존 financial-dashboard 프로젝트 직접 수정.
- 운영 배포 미실시. 현재 운영 URL에 반영되었다고 보고하지 말 것.
- 원본 엑셀, masterData.js, 사업보고서, 비교지수 원천 데이터 변경 없음.
- 저장소 키 v2.7 유지. 표시/UI 버전 변경을 이유로 브라우저 사용자 데이터를 초기화하지 않음.
- 신규 목표 TSR·시나리오 기능은 미구현. 새 PPT 및 시뮬레이션 엑셀 내용 검토는 별도 작업이며 이번 구현 근거로 사용하지 않음.

## 반영 내용

### 공통 및 요약

- Header 및 경영진 요약 버전 표시 v2.8.
- 8.4배배, 중앙값 배배, 레버리지 배배 중복 접미사 제거.
- 누락과 숫자 0 구분 강화 및 비유한 수치(Infinity) 차단.
- 순차입금/EBITDA 음수를 일반 배수 포맷터에서 일괄 적자로 변환하지 않도록 수정. 명시적 적자 옵션은 유지.
- KPI의 하드코딩된 피어 평균을 이용한 저평가/적정 단정 문구 제거. TTM/연간 이익 기준 표기로 교체.
- 요약의 피어 배수 비교는 동일 기간 중앙값 기준으로 유지하며 저평가 단정 대신 낮음/높음 표기.
- 반기 TSR을 연간 TSR로 표시하던 요약 문구 수정. DPS 기여는 %p로 통일.
- 반기 실적, TTM 이익, 시점 재무상태의 구분 안내 수정.
- 회사 전환 시 경영진 브리핑을 재설정하여 타 회사의 기간 선택 상태 잔류 방지.

### A: TSR 구성

- 잘못된 주당배당금(원)/기말주가(원) 조회를 실제 DPS/기말주가 키로 수정.
- 누락된 DPS와 주가를 0으로 변환하는 표시 로직 제거.
- 숫자 2026과 문자열 2026 상반기를 동일 기간으로 매칭하여 CJ제일제당 누락 해소.
- 주가/DPS를 정확한 원 단위로 표시하고 원원 중복 제거.
- DPS 보정 효과의 0과 비영 값 모두 %p 단위 적용. 반올림 후 -0.0%p 방지.
- 양수 DPS만으로 중간배당이라고 추정하던 문구 삭제. 원천 배당 귀속기준 및 반기 특이사항 표시.
- 실제 사용 중인 클래스에 대응하는 CSS 추가로 0 중심 막대, 기준선, 피어 마커 복구.

### B: 시가총액 변동 분해

- 순변동 대비 비중 분모를 부호 있는 실제 시가총액 변동으로 통일.
- 합계 비중을 실제 분해 합계/순변동으로 계산. 순변동 0일 때 비중 미표시.
- 검증 결과를 고정 성공 문구에서 실제 유한 잔차/허용오차 판정으로 변경.
- 2026 종료 시점 표기에 6월 말 및 이익 TTM 구분.
- 분해 엔진에서 TTM 누락 시 반기 EBITDA로 대체하지 않도록 변경.
- 기존 분해 순서는 유지: EBITDA 변화×시작 배수 + 종료 EBITDA×배수 변화 − Net Debt 변화. 인과관계 추정 모델이 아님.

### C: 자본구조

- 11단계 문구를 실제 요약 도식의 6단계로 정정.
- 추가 EV 조정항목 명칭으로 리스·신종자본·비지배지분의 가산 부분 명확화.
- 밝은/어두운 모드의 카드 배경 및 글자 대비 보완.
- 시가총액/Net Debt/EV 원천 입력 존재 여부와 잔차에 따라 검증 상태 표시.

### D: 관리지표 추이

- 피어 최신 행을 무조건 선택하지 않고 선택 회사와 같은 기간으로 매칭.
- min-max 위치를 백분위로 오인하게 하던 분위 문구 제거. 최솟값 0·최댓값 100의 위치로 표기.
- 중앙값 대비 차이에 순현금 문구가 붙는 오류 제거. 배수 차이는 배, 수익률 차이는 %p 적용.
- DPS 차트 축 1자리 소수 및 %p 적용. 다른 수익률은 % 유지.
- 2016–2026H1 기간 표기, 분포 게이지 스타일 복구.

### 가독성 및 인쇄

- 상세 탭 제목·숫자·보조 설명·테이블의 크기와 간격 조정.
- 상세표 기본 접힘 유지.
- InfoTooltip 공통 컴포넌트 도입: 마우스/키보드 포커스/클릭, Escape 종료, 화면 너비 내 배치.
- 설명 텍스트의 스크린리더 연결 및 인쇄 각주 제공.
- 인쇄 이벤트에서 상세표 자동 포함, 인쇄 후 원래 접힘 상태 복귀.
- 큰 상세 섹션의 일괄 페이지 넘김 제한 완화 및 표 머리글 반복.

## 검증 한계 및 인계 조건

- 사업보고서와 원본 엑셀의 재무 수치 전수 재검증을 이번에 실시한 것은 아님.
- 전체 업로드/인라인 편집/저장/복원/구버전 데이터 마이그레이션의 전수 회귀 테스트는 미실시. 기존 재계산 엔진의 모든 결측 처리 문제를 해소했다고 주장하지 말 것.
- 신규 입력의 재무 구성항목 결측을 0으로 처리하는 기존 경로는 추가 점검 필요.
- 생성 PDF의 모든 페이지·모든 회사·모든 기간에 대한 글자 단위 및 페이지 잘림 전수 검수는 미실시.
- 비교지수 시계열 전체값 대조와 모바일 전수 점검은 미실시.
- 운영 배포 전 별도 프리뷰에서 위 잔여 검증 및 사용자 가독성 확인 필요.
- 테스트 성공과 원천 데이터 신뢰성 100%는 다른 주장임. 완료 보고에서 혼용 금지.

## Antigravity 인계

1. 이 문서와 현재 파일을 먼저 확인하고 v2.6/v2.7 코드로 덮어쓰지 말 것.
2. 원본 엑셀 및 masterData는 유지. UI 변경으로 localStorage 삭제 금지.
3. verify_v2_8.mjs를 로컬 5188 서버에서 재실행. 실패를 무시하고 SUCCESS 출력 금지.
4. 남은 회귀 검증과 사용자 화면 확인 후 기존 프로젝트/URL로 배포. 새 운영 프로젝트 생성 금지.
5. 배포 승인을 받은 경우에만 운영 반영하고 빌드 식별자, 배포 시각, 실제 URL과 화면 캡처를 함께 기록.
6. SSL 검증 해제 옵션 사용 금지. 사내 보안 인증서 문제는 승인된 인증서 체인으로 해결.
