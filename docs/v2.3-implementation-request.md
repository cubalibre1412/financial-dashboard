# 이사회 대시보드 v2.3 구현 지시서

## 1. 목적과 원칙

현재 수정된 6개 원본 엑셀 파일을 단일 데이터 기준으로 사용하여, 단순 기업 간 수치 비교를 넘어 **TSR·시가총액 변동의 구조와 경영 관리지표를 함께 해석하는 v2.3**을 구현한다.

- 원본: `../*_TSR_Valuation_2016_2026.xlsx`의 `전체 데이터` 시트
- 신규 열: `AO:AR` (주가수익률, DPS 기반 TSR 보정 효과, 순차입금/EBITDA, EBITDA 증감률)
- 지표 정의의 단일 기준 문서: `docs/v2.3-metric-definitions.md`
- 원천 엑셀의 값·수식·기존 열 정의를 임의 변경하지 않는다.
- 원천에 없는 외부 데이터, 추정치 또는 인과관계 주장을 추가하지 않는다.

## 2. 데이터 모델 및 재계산

1. 엑셀 추출 과정과 `masterData`에 다음 필드를 추가한다. 화면용 라벨을 그대로 사용하고 내부 키는 일관되되 기존 키를 깨지 않는다.

| 엑셀 열 | 표시명 | 계산 기준 |
| --- | --- | --- |
| AO | 주가수익률(가격 기준) | `기말주가 / 기초주가 - 1` |
| AP | DPS 기반 TSR 보정 효과 | `연간 TSR - 주가수익률` |
| AQ | 순차입금/EBITDA (2026H1: TTM) | 순차입금 ÷ EBITDA. 2026H1은 TTM EBITDA 사용 |
| AR | EBITDA 증감률 (2026H1: TTM vs FY2025) | 연간은 전년 EBITDA 대비, 2026H1은 TTM EBITDA와 FY2025 EBITDA 비교 |

2. 2026H1 멀티플·증감률은 아래의 기존 엑셀 TTM 기준을 사용한다.

   - `TTM EBITDA = FY2025 EBITDA - 2025H1 EBITDA + 2026H1 EBITDA`
   - `TTM 지배주주순이익 = FY2025 지배주주순이익 - 2025H1 + 2026H1`
   - 2026H1의 EV와 시가총액은 2026-06-30 시점값이다.
   - 2026H1의 PBR은 시점 지표, ROE는 반기 누적이며 연환산하지 않는다.
   - 2026H1에 적자 또는 EBITDA가 0 이하라 PER·관련 멀티플을 산출할 수 없으면 `N/M`으로 표시하고 0 또는 음수 배수로 표시하지 않는다.

3. 사용자 입력, 엑셀 업로드, 표 인라인 수정 뒤에는 레코드 단위 계산뿐 아니라 기업별 연도 시계열 재계산을 실행한다. EBITDA 증감률은 전년 행이 필요하므로 단일 `recalculateRecord`만으로는 처리하지 않는다.

   - 주가수익률 = `closingPrice / openingPrice - 1`
   - DPS 기반 TSR 보정 효과 = `annualTSR - priceReturn`
   - 순차입금/EBITDA는 2026H1에서 TTM EBITDA 사용
   - EBITDA 증감률은 2026H1에서 `TTM EBITDA / FY2025 EBITDA - 1`, 연간은 당해 EBITDA / 전년 EBITDA - 1
   - 전년 EBITDA가 0 이하이거나 없으면 증감률은 빈값(`—`)으로 둔다.

4. 다음 기존 정의를 변경하지 않는다.

   - 순차입금 = 차입금 − (현금및현금성자산 + 단기금융자산 + 단기투자자산)
   - Net Debt = 순차입금 + 리스부채 + 신종자본증권 + 비지배지분
   - EV = 시가총액 + Net Debt
   - 순현금 여부 = 순차입금 < 0

`Net Debt/EBITDA`는 화면에 레버리지 지표로 새로 만들지 않는다. 여기서 Net Debt는 EV 조정항목이라는 사용자 정의이므로, 부채부담 해석에는 **순차입금/EBITDA**만 쓴다.

## 3. 화면 고도화: 경영진 핵심 인텔리전스 브리핑

기존의 단순 순위·기업 비교 화면을 유지하되, 아래 4개 분석을 추가한다. 이들은 모두 원천 엑셀의 현재 값으로만 계산한다.

### A. TSR 구성 카드

선택 기업·선택 기간에 대해 다음을 같은 스케일로 보여준다.

- 연간 TSR
- 주가수익률(가격 기준)
- DPS 기반 TSR 보정 효과
- 동기간 피어 중앙값 및 선택 가능한 벤치마크(가능한 경우)

표시 문구: `DPS 기반 TSR 보정 효과는 결산 귀속 DPS를 연말 재투자하는 현재의 간편 TSR 방식에서 산출한 값이며, 실제 배당락일 재투자 수익률 기여도와는 다를 수 있습니다.`

### B. 시가총액 변동 분해

선택한 두 시점 사이의 시가총액 변동을 아래 3개 요인으로 보여주는 워터폴 또는 브리지 차트를 만든다.

`시가총액 = EBITDA × EV/EBITDA − Net Debt`

분해식은 다음처럼 시작 EBITDA와 종료 EBITDA를 사용한다.

`시가총액 변화 = (종료 EBITDA − 시작 EBITDA) × 시작 EV/EBITDA + 종료 EBITDA × (종료 EV/EBITDA − 시작 EV/EBITDA) − (종료 Net Debt − 시작 Net Debt)`

- 2026H1을 종료시점으로 고르면 EBITDA·EV/EBITDA에는 TTM 값을 사용한다.
- 시작/종료 EV·시가총액·Net Debt 및 브리지 합계가 원천 계산식과 일치하는지 검증한다.
- 분해는 기계적 산술 분해이며 원인 분석 또는 시장의 인과 판단으로 표현하지 않는다.

### C. 자본구조·EV 연결 워터폴

선택 시점의 다음 연결을 명확하게 시각화한다.

`차입금 → 현금 및 단기금융자산 차감 → 순차입금 → 리스부채·신종자본증권·비지배지분 가산 → Net Debt → 시가총액 가산 → EV`

- 순차입금과 Net Debt를 합치거나 서로 대체하지 않는다.
- 순현금 뱃지는 순차입금이 음수일 때만 표시한다.

### D. 핵심 관리지표 트렌드와 피어 위치

기업별 2016~2026H1 시계열에 아래 4개를 추가하고, 최신 시점의 피어 중앙값·상/하위 범위를 함께 표시한다.

- 주가수익률
- DPS 기반 TSR 보정 효과
- 순차입금/EBITDA
- EBITDA 증감률

2026H1에는 모든 해당 카드·축·툴팁에 `TTM vs FY2025` 또는 `TTM`을 명확히 표기한다. 연간 지표와 2026H1 TTM 지표가 같은 정의인 것처럼 보이게 하지 않는다.

## 4. 정의·출처·가독성

- 각 신규 지표 옆에 정보 아이콘을 두고 `docs/v2.3-metric-definitions.md`의 정의와 한계를 그대로 반영한다.
- 화면 또는 데이터 사전에서 원천 파일명, 시트명(`전체 데이터`), 열명(AO~AR), 결산/반기 기준일을 조회할 수 있게 한다.
- 금액은 기존 원 단위 원천을 유지하고, 화면 표시는 조원/억원으로 통일한다. 반올림 전 원천값으로 계산한다.
- 퍼센트는 기본 소수점 첫째 자리, 배수는 소수점 첫째 자리로 표시한다. 미산출은 `—` 또는 `N/M`으로 명시한다.
- 자동 생성 문구는 사실·수치·기간만 진술한다. "원인", "개선", "저평가", "시장 기대" 등 검증되지 않은 해석은 쓰지 않는다.

## 5. 필수 검증 및 완료 보고

구현 후 다음을 모두 실행·보고한다.

1. 수정된 원본 엑셀 6개 파일을 다시 추출했는지 확인한다.
2. 각 회사 2016~2026H1의 AO:AR 값이 엑셀과 일치하는지 대조한다.
3. `순차입금`, `Net Debt`, `EV`의 기존 항등식과 2026H1 TTM 멀티플을 재검증한다.
4. 풀무원 2016~2025 누적 TSR은 **-24.35%**이며 연간 TSR 연쇄곱과 일치해야 한다. 과거 `+253.9%` 표기와 "원천 확인 필요" 뱃지는 제거한다.
5. CJ제일제당·대상의 2026H1 TTM 지배주주순이익이 음수인 경우 PER를 `N/M`으로 표시하는지 확인한다.
6. 데이터 업로드·인라인 수정 후 시계열 지표가 다시 계산되는지 확인한다.
7. 빌드, 주요 화면 렌더링, 콘솔 오류 여부를 확인한다.
8. 배포는 정상 TLS 검증으로 먼저 시도한다. 사내 프록시로 TLS 오류가 재현될 때에만 해당 배포 명령 1회에 한정해 우회하고, 배포 URL을 별도로 검증한다. 전역 SSL 검증 해제나 영구 설정 변경은 금지한다.

완료 보고에는 수정 파일, 엑셀 대조 결과, 수식·표시 검증 결과, 미해결 사항(있다면)을 사실 기준으로 구분하여 작성한다.
