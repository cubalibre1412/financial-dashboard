# v3.2 변경 이력: 데이터 엑셀 다운로드

## 반영 내용

- 회사별 다운로드: 상단의 `회사 데이터 다운로드` 버튼으로 현재 선택한 회사의 계산·보정 후 전체 시계열을 `.xlsx`로 다운로드합니다.
- 비교지수 다운로드: `비교 지수 & 벤치마크` 화면에서는 같은 위치의 버튼이 `비교지수 다운로드`로 바뀌며, KRX 비교지수와 아파트 매매가격 시계열을 별도 파일로 다운로드합니다.
- 파일 구성: 회사 파일은 `전체 데이터`, `다운로드 정보` 시트로 구성합니다. 비교지수 파일은 `KRX 비교지수`, `아파트 매매가격`, `다운로드 정보` 시트로 구성합니다.
- 이력성: 다운로드 정보 시트에 데이터 패키지 버전, 원천 갱신 시각, 다운로드 시각, 행 수를 남깁니다. 브라우저 내 로컬 경로는 포함하지 않습니다.

## 검증 기준

- 회사별 파일은 `전체 데이터` 행 수가 선택 회사 시계열 행 수와 일치해야 합니다.
- 비교지수 파일은 KRX 비교지수와 아파트 매매가격 행 수가 데이터 패키지와 각각 일치해야 합니다.
- 배포 전 `npm run verify:downloads`가 실제 XLSX 직렬화 후 재열기로 시트명과 행 수를 확인합니다.

## 버전 기준

- 화면 기능 버전은 `v3.2`입니다.
- 원천 데이터 패키지 버전은 데이터 구조 버전과 갱신 시각을 별도로 표시합니다.
