# v2.3 분석 지표 정의

## 적용 범위

이 문서는 6개사 `전체 데이터` 시트와 이사회 대시보드에서 공통으로 사용하는 분석 지표의 정의를 정한다. 원천 재무 데이터와 기존 TSR·Valuation 산식은 유지한다.

## 주가수익률(가격 기준)

`기말주가 ÷ 기초주가 − 1`

배당을 포함하지 않는 해당 기간의 주가 변동률이다. 2026H1은 2026년 상반기 단일 기간의 주가 변동률이다.

## DPS 기반 TSR 보정 효과

`연간 TSR − 주가수익률`

현재 원본의 결산 귀속 DPS 및 재투자 가정을 기준으로 TSR과 가격수익률의 차이를 나타낸다. 실제 배당 지급일·배당락일·재투자일을 모두 반영한 정밀 배당 귀속 분석과는 다르므로, 화면에는 `DPS 기반 TSR 보정 효과`로 표시한다.

## 순차입금/EBITDA

`순차입금 ÷ EBITDA`

순차입금은 `차입금 − (현금및현금성자산 + 단기금융자산 + 단기투자자산)`이다. 차입 부담을 EBITDA와 비교하는 보조 지표이며, 현재 대시보드의 `Net Debt`는 리스부채·신종자본증권·비지배지분까지 포함한 EV 조정항목이므로 이 비율의 분자로 사용하지 않는다.

2026H1의 분모는 `FY2025 − 2025H1 + 2026H1`의 TTM EBITDA를 사용한다. EBITDA가 0 이하이면 표시하지 않는다.

## EBITDA 증감률

정규 연도는 `당기 EBITDA ÷ 전기 EBITDA − 1`이다.

2026H1은 반기 EBITDA와 FY2025 EBITDA를 직접 비교하지 않는다. `2026H1 TTM EBITDA ÷ FY2025 EBITDA − 1`을 사용한다. FY2025 EBITDA가 0 이하이면 표시하지 않는다.

## 해석 원칙

- 낮은 EV/EBITDA를 저평가, 높은 EV/EBITDA를 고평가로 단정하지 않는다.
- EBITDA는 영업 성과 지표이며 현금흐름이나 배당가능이익과 동일하지 않다.
- 순차입금/EBITDA는 차입 부담을 설명하는 지표다.
- Net Debt는 EV 조정항목으로 별도 표시한다.
