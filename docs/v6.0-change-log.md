# BOARD INTEL v6.0 변경 기록

## 목적

PPT `주주가치 성과측정 및 관리체계(안)_v2.9`의 결론 중심 보고 구조를 웹 대시보드에 반영하되, 기존 A~E 상세분석과 원천 데이터 검증 기능은 유지한다.

## 주요 변경

1. 풀무원 기본 화면에 `이사회 보고` 탭 신설
2. 이사회 보고 ① `10년 성과 진단`
   - FY2016→FY2025 공식 평가와 FY2026H1 최신 모니터링 분리
   - EBITDA·EV·Net Debt·Equity Value 및 EV 중 Equity 비중 연결
   - 피어 5사, 삼양 제외 4사, Wet Food 2사 중앙값 병렬 표시
   - 공식 기간 1Y·3Y·10Y 표시, 5Y는 상세분석 참고지표로 유지
   - 시장·대체투자 비교는 풀무원 배당 재투자 TSR, KOSPI·생활소비재·국채 TR, 전국 아파트 PR을 ₩100 기말가치로 표시
3. 이사회 보고 ② `목표·관리체계`
   - PPT v2.9의 T-TSR·E-TSR·Gap과 목표 가정을 `미승인 시나리오`로 분리
   - 목표 TSR 구성과 E-TSR→T-TSR Gap 분해를 동일 차트로 혼합하지 않도록 고지
   - 3단계·8개 관리원칙 및 연간 보고 주기 표시
   - 책임자·완료일·진행상태는 원천 미제공으로 입력 필요 상태 표시
4. 화면 정보 위계 변경
   - 경영진/이사회 결론을 최신 KPI 카드보다 먼저 배치
   - 기존 KPI, A~E, EV 차트, 원천 데이터 그리드는 하단 근거·상세 분석으로 유지
5. 상세 연결
   - 자본구조 상세 → C
   - 피어 추이 상세 → D
   - 목표 가정 검토 → E 시뮬레이션
   - 시장 비교 전체보기 → 비교지수 센터
6. 데이터 기반 경영진 코멘트
   - 장기 구조: EBITDA·EV·Net Debt·Equity Value의 10년 변화 해석
   - 상대성과: 1Y 개선과 10Y 피어 격차를 함께 제시
   - 최신 신호: 2026H1 TSR·TTM EBITDA 증감·Net Debt 변화 병렬 점검
   - 경영 시사점: EBITDA 성장, Net Debt 축소, 현금창출력 및 시장평가를 통합 관리
   - 외부 근거가 필요한 시장 원인이나 인과관계는 단정하지 않음

## 측정 기준

- 피어 비교: 세전·귀속 DPS·배당 비재투자 단순누적
- 시장·대체투자 비교: 풀무원 배당 재투자 TSR 및 지수 TR
- 아파트: 전국 아파트 가격변동지수(PR)
- 공식 평가기간: 1Y·3Y·10Y
- 5Y: 참고지표
- FY2026H1 KOSPI TR +102.7%: 사용자 원천 확인 완료

## v6.0 인플레이스 화면 보완

- 버전 표기 `BOARD INTEL v6.0` 유지
- `10년 성과 진단`을 FY2016→FY2025 공식 평가로 고정
- 2026H1 KPI 카드를 `최신 모니터링 — FY2026 1H` 독립 구역으로 분리
- TSR은 반기, EBITDA·배수는 TTM, 재무상태는 2026.06.30 기준임을 배지와 툴팁으로 명시
- 공식 진단의 `최신 신호` 코멘트를 최신 모니터링 구역으로 이동
- 공식 진단 측정 기준에서 FY2026H1 벤치마크 확인 문구를 제거해 평가기간 혼합 방지
- 최신 KPI 내 10년 TSR 표기를 `공식 10Y TSR ('16초~'25말)`로 명확화
- 공식 이사회 진단에는 연도 선택기를 추가하지 않고, 기존 A~C 상세분석의 기준연도 선택 기능을 유지
- 운영 자산 확인: `최신 모니터링`, `TSR · 반기`, `EBITDA·배수 · TTM`, `공식 10Y TSR`, 최신 모니터링 전용 스타일 포함
