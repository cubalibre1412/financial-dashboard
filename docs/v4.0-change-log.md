## 1. 반영 범위 및 주요 변경 사항

- **화면 버전 표기 최신화**:
  - 상단 대시보드 헤더 배지: `BOARD INTEL v4.0`
  - 경영진 핵심 인텔리전스 브리핑 배지: `v4.0`
- **스토리지 마이그레이션 자동화**:
  - 브라우저 저장소 키 `excelyze_company_data_v4.0` 적용
  - 이전 버전(`v3.3`, `v3.2`, `v3.1`, `v2.x` 등)의 사용자 로컬 저장 데이터를 `v4.0`으로 자동 승계 및 stale 검증
- **전체 데이터 엑셀(.xlsx) 수식 다운로드 시스템 고도화**:
  - 원천 입력값(기초/기말주가, DPS, 차입금, 현금, EBIT, 상각비, 자본 등)은 **값(Value)**으로 보존
  - 핵심 계산 열 및 파생지표에 **실제 Excel 수식(Formula)** 부여:
    - **연간 TSR**: `=IFERROR((기말주가-기초주가+DPS)/기초주가,"")`
    - **순차입금(원)**: `=IF(OR(차입금="",현금=""),"",차입금-현금-단기금융자산-단기투자자산)`
    - **Net Debt(B)**: `=IF(순차입금="","",순차입금+리스부채+신종자본증권+비지배지분)`
    - **EV(원)**: `=IF(OR(시가총액="",Net Debt=""),"",시가총액+Net Debt)`
    - **EBITDA(원)**: `=IF(EBIT="","",EBIT+감가상각비+투자부동산감가상각비+무형자산상각비)`
    - **EV/EBITDA**: `=IFERROR(EV/(IF(LEFT(연도,4)="2026",TTMEBITDA,EBITDA)),"")` (2026H1은 TTM EBITDA 참조)
    - **PER**: `=IF(실제순이익<=0,"",시가총액/(IF(LEFT(연도,4)="2026",TTM순이익,순이익)))` (2026H1은 TTM 순이익 참조)
    - **PBR**: `=IFERROR(시가총액/자기자본,"")`
    - **ROE**: `=IFERROR(순이익/평균자기자본,"")`
    - **주가수익률(가격 기준)**: `=IFERROR((기말주가-기초주가)/기초주가,"")`
    - **DPS 기반 TSR 보정 효과**: `=IFERROR(연간TSR-주가수익률,"")`
    - **순차입금/EBITDA (2026H1: TTM)**: `=IFERROR(순차입금/(IF(LEFT(연도,4)="2026",TTMEBITDA,EBITDA)),"")`
    - **EBITDA 증감률 (2026H1: TTM vs FY2025)**: 전년 대비 증감률 수식
- **다운로드 파일 왕복 직렬화 검증**:
  - `npm run verify:downloads` 스크립트를 통해 생성된 XLSX 파일을 메모리상에서 재개방하여 6개사 전 기간의 수식 속성(`cell.f`) 존재 및 TTM 분모 참조 완전 검증

## 2. 배포 전 사전 검증 (`npm run release:prepare`)

1. `npm run refresh:data`: 6개사 66행 원천 정합성 검증 완료 (`VALIDATION PASSED`)
2. `npm run audit:context`: 5개 회사 문맥 및 권한 규칙 검증 통과 (`CONTEXT AUDIT PASSED`)
3. `npm run verify:downloads`: 6개사 계산 열 엑셀 수식(`cell.f`) 및 TTM 참조 무결성 검증 통과
4. `npm run build`: Vite 프로덕션 빌드 완료 (`dist/` 생성 성공)
