## 데이터 반영 방식

- `scripts/refresh-data.mjs --apply`로 원본 엑셀의 `전체 데이터` 시트를 다시 읽어 6개사 66개 행 데이터 패키지를 생성
- 기존 브라우저 저장 데이터의 풀무원 2026 기초주가 또는 TTM EBITDA가 최신 마스터 데이터와 다르면 자동으로 원본 데이터로 갱신
- 과거 임시 런타임 보정은 제거하고 원본 엑셀을 단일 기준으로 사용
