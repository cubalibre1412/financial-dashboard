## 1. 반영 범위 및 주요 변경 사항

- **풀무원 2017년 DPS 원천 정정 (`115.3원` → `115원`)**:
  - 원천 엑셀 `풀무원_TSR_Valuation_2016_2026.xlsx` 및 `MASTER_DATA`의 2017년 DPS를 정수로 정정 반영
  - 원천 엑셀 `전체 데이터` 시트의 연동 수식(수령 배당금, 추가 매수주식수, 기말 보유주식수, 최종가치, 연간 TSR) 무결성 유지
  - 풀무원 2016~2026년 엑셀↔대시보드 연동값 불일치 **0건** 확인
- **10년 TSR 최종 표시값 검증**:
  - **비재투자 (단순누적)**: `-24.8763%`
  - **재투자 (복리재투자)**: `-24.3519%`
  - 시장·대체투자 비교: 배당 재투자 TSR 유지
  - 피어 비교: 세전·귀속 DPS·비재투자 단순누적 TSR 유지
- **브라우저 스토리지 마이그레이션 및 자동 갱신 (`v5.0`)**:
  - 스토리지 키 `excelyze_company_data_v5.0` 적용
  - 기존 브라우저 로컬 스토리지에 2017년 DPS가 `115.3원`으로 남아 있는 경우, 접속 시 즉시 최신 `115원` 원천 데이터로 자동 갱신
- **화면 버전 표기 최신화**:
  - 상단 대시보드 헤더 배지: `BOARD INTEL v5.0`

- **엑셀 다운로드 수식 검증**:

## 2. 사전 검증 (`npm run release:prepare`)

1. `npm run refresh:data`: 6개사 66행 원천 정합성 검증 완료 (`VALIDATION PASSED`)
2. `npm run audit:context`: 5개 회사 문맥 및 권한 규칙 검증 통과 (`CONTEXT AUDIT PASSED`)
3. `npm run verify:downloads`: 풀무원 2017년 DPS 115원 및 6개사 계산 열 엑셀 수식(`cell.f`) 무결성 통과
4. `npm run build`: Vite 프로덕션 빌드 완료 (`dist/` 생성 성공)
