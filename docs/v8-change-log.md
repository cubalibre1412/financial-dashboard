# v8.0 승인 개선안 반영 — 2026-10-13

## 범위 및 상태
이사회용·실무자용 화면을 v8.0으로 표시. 기존 승인 데이터·TSR 정책 유지. 원천 엑셀 수정 없음. GitHub 반영·운영 배포는 별도 승인 단계이며 이번 수정에 포함하지 않음.

## 데이터 통제
이사회 화면은 MASTER_DATA 승인 데이터만 사용. 브라우저 편집·업로드 작업본은 실무자용에만 반영. 작업본 표시 추가. 이사회 업로드·백업 버튼 제거. 기존 브라우저 작업본을 삭제하지 않음.

## 계산과 표시
ROE = 해당 기간 지배주주순이익 / 승인된 평균자기자본. PER TTM 순이익과 분리. 평균자기자본 없을 때 임의로 기말자본 대체하지 않음. 입력 부족 시 TSR·Net Debt·EV·EBITDA·레버리지 파생값 초기화. 실제 0인 배당과 배당 미입력 구분. 피어 고정 8.8배 제거, 선택 결산의 유효 배수 중앙값·표본 수 표시. 적자 PER와 자료 부족 구분. 벤치마크 결측값 숫자 서식 예외 보완.

## 이사회 구성
공식 FY2016~FY2025 비재투자 TSR 고정. 피어 5사 중앙값 대표, 4사 보조. TSR 격차 %p 적용. 시장 카드에 풀무원 재투자 TSR과 KOSPI TR 병기. 결산 KPI 기간 선택·해당 기간 피어 비교. 관측 사실과 경영진 점검 질문 분리. 반복 제목·단독 탭 제거. 실무자용 최신 모니터링 기간 안내 동적화.

## 운영 기준
GitHub 자동 배포는 원천 엑셀 자동 추출을 의미하지 않음. 원천 변경 시 refresh:data, 검증, 변경 보고서 검토 후 데이터 패키지 반영. 비적용 금융·상각 항목의 기존 원천 null→0 정책은 별도 계정별 확정 없이 전면 변경하지 않음.
