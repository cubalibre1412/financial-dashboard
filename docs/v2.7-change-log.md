  - 시작·종료기간 선택 및 유효성 검증 유지

  - 산식 대조표 기본 접힘

- C. 자본구조·EV 연결
  - 기준시점 선택 유지
  - 순차입금·Net Debt·EV 구분 유지
- D. 관리지표 추이
  - 전체 시계열, 2026H1 구분, 최신 피어 분포 분리 유지

## 이번 수정에서 해소한 결함

- 상세 화면의 유틸리티 스타일 미적용
  - 원인: Tailwind 문법의 `className`이 남아 있었으나, 실행 환경은 Tailwind를 로드하지 않아 설명·카드·표의 여백과 정렬이 무너짐
  - 조치: 상세 브리핑 영역에 한정한 호환 스타일을 적용하고, 화면 전반의 여백·행간·카드·표·반응형 규칙을 복구
- 시가총액 분해 표의 `데이터 없음` 및 `NaN원`
  - 원인: 계산 엔진의 실제 반환값 `sumEffect` 대신 존재하지 않는 `sumOfEffects`를 화면이 참조
  - 조치: 실제 분해 합계 필드로 연결하고, 항등식 오차를 `실제 시총 변동 − 3개 효과 합계`로 직접 표시
- 시가총액 워터폴의 Net Debt 막대 위치
  - 원인: Net Debt 효과의 시작 좌표가 직전 단계가 아닌 이전 단계로 설정됨
  - 조치: EBITDA 효과 → 배수 효과 → Net Debt 효과의 누적 순서에 맞게 좌표 수정
- 설명·고지 문구의 과밀 노출
  - 조치: TSR, 시가총액 분해, 자본구조, 관리지표의 긴 방법론 문구를 기본 화면에서 제거하고, 정보 아이콘의 마우스오버·키보드 포커스 오버레이로 전환
- 브라우저 저장 데이터 승계
  - 조치: 저장 키를 v2.7로 전환하고 v2.6 저장값을 이전 버전 목록에 포함하여, 기존 사용자의 입력 데이터를 유지한 채 최신 화면으로 이동
